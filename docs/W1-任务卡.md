## D2（明天，约 60 分钟）：装 Linux

Windows 上读不到 `/proc/stat`，所以真实数据要在 WSL 里跑。**这一步绕不过去**，
而且面试问的 Linux 问题（进程、/proc、文件描述符）你也需要一台能摸的 Linux。

1. **以管理员身份**打开 PowerShell，执行：

```powershell
wsl --install
```

2. 重启电脑
3. 重启后会弹出 Ubuntu 窗口，设置用户名和密码（**密码输入时不显示，是正常的**）
4. 在 Ubuntu 里装 Go：

```bash
sudo apt update && sudo apt install -y golang-go
go version
```

5. 进项目目录跑起来：

```bash
cd /mnt/c/Users/jmshc/Documents/deepseek-harness/default-workspace/mini-datakit
go run ./cmd/agent -config configs/agent.json
```

**验收：屏幕上每 2 秒刷出几行 `cpu,core=cpu0,... usage=x.x`。**

按 `Ctrl+C` 退出。

> 用 VS Code 打开 WSL 里的代码：装 `WSL` 扩展，然后在 Ubuntu 里执行 `code .`。

## 卡住了怎么办

| 现象 | 原因 | 解决 |
|---|---|---|
| `go : 无法将"go"项识别为...` | PATH 没生效 | 关掉所有终端重开；还不行就重启 |
| `go.mod file not found` | 不在项目根目录 | `cd` 到 `mini-datakit` 那一层 |
| `package mini-datakit/... is not in std` | 同上，或 `go.mod` 被删了 | 确认 `go.mod` 在根目录 |
| 测试失败但代码没改 | 大概率是 `TestLineIsStable` 挂了 | 说明你的 `sortedKeys` 被改坏了 |
| `wsl --install` 报错 | 需要管理员权限 / 需要开虚拟化 | 先开 BIOS 的 VT-x，再用管理员 PowerShell |
| 运行 agent 报 `no such file /proc/stat` | 在 Windows 里跑的 | 去 WSL 里跑 |
| 编译报错看不懂 | 正常 | 把**完整**报错（含行号）贴给我 |
